# Reading Results

## Learning elements

After processing completes, results are displayed as a grid of **learning
element** cards. Each card shows:

- **Topic** — a short title for the knowledge area
- **Content** — the extracted text
- **Bloom's badge** — a colored badge indicating the cognitive level
- **Source page** — page number in the original document (when available)

## Bloom's taxonomy levels

Each element is classified into one of six [Bloom's taxonomy](https://en.wikipedia.org/wiki/Bloom%27s_taxonomy) levels, represented
by a colored badge:

| Level | Badge Color | Meaning |
|-------|-------------|---------|
| **Remember** | Gray | Recall facts and basic concepts |
| **Understand** | Blue | Explain ideas or concepts |
| **Apply** | Green | Use information in new situations |
| **Analyze** | Yellow | Draw connections among ideas |
| **Evaluate** | Orange | Justify a stand or decision |
| **Create** | Purple | Produce new or original work |

If an element cannot be classified, it is labeled **Unclassified** with a muted badge.

## Filtering results

Above the results grid, you'll find:

- **Level filter buttons** — click a Bloom's level to show only elements at that level; click **All** to clear the filter
- **Search box** — type to filter elements by topic or content text

Filters combine — you can search within a specific level.

## Bloom's distribution summary

At the top of the results page, a **distribution bar** shows the percentage of
elements at each Bloom's level. This gives you a quick visual overview of how
the course material is balanced across cognitive levels.

For example, a course heavy on **Remember** and light on **Analyze** or
**Create** may indicate a need for higher-order learning activities.

## Rationale

Each element includes a **rationale** — a brief explanation of why the
processor assigned a particular Bloom's level. This helps educators verify
the classification and understand the reasoning behind it.
